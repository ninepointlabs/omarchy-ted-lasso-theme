# Ted Lasso Theme for Omarchy

A warm, navy-and-gold [Omarchy](https://omarchy.org/) theme inspired by AFC Richmond and the "BELIEVE" sign — dark background, gold accents, and three matching wallpapers.

## Install

```bash
omarchy theme install https://github.com/ninepointlabs/omarchy-ted-lasso-theme
omarchy theme set "Ted Lasso"
```

Or clone it manually into `~/.config/omarchy/themes/ted-lasso/` and run `omarchy theme set ted-lasso`.

## Palette

| Role | Color |
|---|---|
| Accent / Yellow | `#F2C230` |
| Background | `#16283D` |
| Foreground | `#F5ECD9` |
| Green | `#5FA85D` |
| Red | `#D64545` |
| Blue | `#4F8FD9` |

See [`colors.toml`](colors.toml) for the full palette.

## Backgrounds

Three included wallpapers: `believe-wall.png`, `cozy-tan.png`, `pitch-lights.png`. Cycle through them with `omarchy theme bg next`.
